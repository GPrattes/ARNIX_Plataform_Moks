# ARNIX Precific - UI Mocks & Prototypes

Bem-vindo ao diretório `.mock/` do projeto **ARNIX Precific**. Este diretório contém toda a interface de usuário (Frontend), protótipos visuais e páginas de captação de investidores criadas para demonstração e validação do produto.

O ambiente de mocks foi construído para apresentar a visão da plataforma com um design premium, utilizando conceitos de *Glassmorphism*, gradientes responsivos e componentes fluidos, focado tanto na usabilidade corporativa (SaaS) quanto no encantamento para investidores e *Venture Capital*.

## 📁 Estrutura de Páginas

Abaixo estão as principais páginas contidas neste diretório:

### 💼 Portal Institucional e Investidores
- **`lg.html` (Login & Investor Access)**: Página de login da plataforma. Atua também como um portal de captação, contendo links de contato direto e animações em Canvas.
- **`sobre.html` (Visão e Tese de Investimento)**: Página de apresentação corporativa detalhando a tese de investimento, diferenciais tecnológicos (IA, Governança, Escalabilidade) e o TAM endereçável.
- **`ceo.html` (Liderança)**: Página de apresentação do board executivo (Gabriel Prattes - Eng & Dev / João Paulo Calafate - Comercial & Mkt) com links diretos de contato.

### 📊 Painel SaaS (Sistema)
- **`index.html` (Dashboard)**: O painel inicial do usuário simulando métricas financeiras, gráficos de rentabilidade e alertas rápidos.
- **`calculadora.html`**: Interface interativa onde o usuário simula a precificação baseada em custos, impostos e margem desejada.
- **`propostas.html`**: Gerenciador de propostas comerciais geradas, exibindo o status de cada cliente.
- **`clientes.html`**: Gerenciador de carteira de clientes.

## 🎨 Design & Tecnologia
- **Sem Frameworks Pesados**: Todas as páginas foram construídas utilizando **HTML5, CSS3 Nativo (Variáveis e Flex/Grid) e Vanilla JavaScript**. Isso garante que o mock rode instantaneamente em qualquer navegador sem a necessidade de pacotes como npm ou processos de build.
- **Tipografia**: Utiliza `Space Grotesk` para títulos (trazendo um tom tech e moderno) e `Inter` para o corpo de texto (focado na legibilidade de dados numéricos).
- **Responsividade**: As telas são responsivas, contendo uma Sidebar adaptativa para dispositivos móveis (drawer menu) e desktops (collapse menu).

## 🚀 Como Executar

Por ser um protótipo estático, **não há necessidade de servidor ou banco de dados** para visualização:
1. Navegue até esta pasta `.mock/`.
2. Dê um clique duplo em qualquer arquivo `.html` (por exemplo, `lg.html` ou `index.html`).
3. O arquivo abrirá diretamente no seu navegador padrão.

> **Nota:** Os botões e formulários nestas páginas contêm lógicas simuladas (mockadas) via JavaScript (presentes nos arquivos `.js` ou scripts no final das páginas). O botão de login em `lg.html`, por exemplo, contém um atalho (*Bypass*) para acessar o dashboard sem autenticação real.
